# Memory Bank operating rule

Use `memory-bank/` as the durable local project memory for this repository.

## Read at task start
Before meaningful work, read:
- `memory-bank/projectbrief.md`
- `memory-bank/productContext.md`
- `memory-bank/techContext.md`
- `memory-bank/systemPatterns.md`
- `memory-bank/repoMap.md`
- `memory-bank/activeContext.md`
- `memory-bank/progress.md`
- `memory-bank/privacyNotes.md`

## Update when needed
Update Memory Bank when:
- a meaningful milestone is completed,
- architecture understanding improves,
- priorities or decisions change,
- the repo map becomes stale,
- you are ending the session.

## What to keep concise
- `activeContext.md`: what is happening now
- `progress.md`: what is done / in progress / next
- `repoMap.md`: fast index of routes, features, entry points, and hot files
- `systemPatterns.md`: durable architecture rules and ownership notes

## Redaction rule
Never store real patient, personnel, payment, contact, incident, or scheduling data in Memory Bank files.
