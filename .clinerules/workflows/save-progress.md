# Save progress and prepare handoff

Use this workflow before ending a session or after a meaningful milestone.

## Steps
1. Update `memory-bank/activeContext.md`.
2. Update `memory-bank/progress.md`.
3. Update `memory-bank/repoMap.md` or `memory-bank/systemPatterns.md` if project understanding changed.
4. Keep all updates concise and sanitized.
5. Return a short handoff summary with:
   - current objective,
   - files changed,
   - validation completed or pending,
   - residual risks,
   - immediate next step.
