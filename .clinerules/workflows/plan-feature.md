# Plan a feature or refactor in batches

Use this workflow when the task is medium or large and should be broken into steps.

## Steps
1. Read `memory-bank/`.
2. Restate the user goal and priority.
3. Identify the affected lanes and likely files.
4. Break the work into phases, then smaller execution batches.
5. For each batch, define:
   - objective,
   - files likely in scope,
   - risk level,
   - validation required,
   - rollback note.
6. Mark which batches are:
   - safe for Act directly,
   - should be Plan -> Act,
   - should use `/deep-planning`.
7. Do not implement unless the user explicitly approves execution.
